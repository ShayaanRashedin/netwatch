# Changelog

All notable changes to NetWatch are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-29

### Added

- Linux `/proc` collection for IPv4/IPv6 TCP and UDP sockets
- Process ownership and identity correlation, including PID-reuse protection
- Deterministic socket lifecycle and state-change events
- Explainable behavioral detection with risk scores and cooldowns
- Bounded asynchronous SQLite persistence, retention, and history queries
- Read-only JSON API and responsive live dashboard
- Installable CMake targets, presets, TGZ packaging, and version commands
- Hardened systemd service definitions and environment configuration
- Multi-stage Docker image and Linux host-observability Compose stack
- Automated installed-artifact smoke test and controlled alert demo
- Tagged GitHub release workflow with SHA-256 checksums
- Security policy, contribution guide, deployment guide, and MIT license
